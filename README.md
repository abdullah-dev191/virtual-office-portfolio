# Muhammad Abdullah, interactive office portfolio

Walk through a 3D office: security opens the gate, reception walks you to a room (Work Studio, Tech Lab, Operations, Meeting Room) or knocks on the boss cabin. A Classic view gives a plain scrolling page.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # static export in ./out
docker compose up --build
```

Edit your details in `src/content/`. Controls: click or tap the floor, or use WASD and arrow keys.
